# FPGA 小模块说明

本仓库收录了一组面向数字信号处理的 Verilog 小模块，主要覆盖 CORDIC 数学运算、自适应滤波、固定系数滤波和伪随机激励。本文以当前 RTL 源码为准，第一章说明各模块自身的功能与约束，第二章说明模块组合后可实现的系统功能，第三章给出使用总结。

除特别说明外，各模块均使用 `i_clk` 上升沿工作，并使用低有效异步复位 `i_rst_n`。

## 第一章：各模块功能

### 1.1 CORDIC 正弦/余弦计算器

相关文件：

- `Cordic_24.v`：24 位相位输入和 24 位正弦、余弦输出。
- `Cordic_48.v`：48 位相位输入，输出位宽由 `DOUT_WIDTH` 指定，默认 16 位。

两个版本都使用 CORDIC 旋转模式，把全圆周相位映射到收敛区间后，通过流水迭代同时计算 `cos` 和 `sin`，无需正弦 ROM。

| 版本 | 相位编码 | 迭代结构 | 输出格式 |
|---|---|---|---|
| 24 位 | 有符号 24 位圆周相位，`0x800000` 表示 `-π`（与 `+π` 同一点） | 象限预处理 + 24 次迭代 | 有符号 Q1.23 |
| 48 位 | 有符号 48 位圆周相位，`0x4000_0000_0000` 表示 `+π/2` | 象限预处理 + 47 次有效迭代 | 有符号 Q1.`(DOUT_WIDTH-1)` |

模块可每拍接收一个新相位，适合生成正交载波、连续波、调频波和调相信号。使用时需要将控制信号延迟到与 CORDIC 流水输出对齐。

> 注意：两个文件中的顶层模块名都为 `Cordic`。工程只能选择其中一个版本，或先修改模块名再同时使用。

### 1.2 CORDIC 反正切/模长计算器

相关文件：

- `Cordic_Atan2_24.v`：输入、相位和模长均为 24 位。
- `Cordic_Atan2_48.v`：输入位宽 `DIN_WIDTH`、相位位宽 `PHASE_WIDTH` 和模长位宽 `MAG_WIDTH` 可配置，默认分别为 16、48、16 位。

模块使用 CORDIC 向量模式，输入直角坐标 `(x, y)`，同时输出：

- `o_phase = atan2(y, x)`；
- `o_phase_mag ≈ sqrt(x² + y²)`。

24 位版本采用输入级增益预补偿，数据通路为象限预处理加 24 次迭代。48 位版本内部以 48 位相位完成 47 次迭代，并增加模长补偿及相位、模长对齐寄存器；零向量输入明确输出零相位和零模长。两者均为持续流水结构。

典型用途包括 IQ 相位提取、幅度检测、直角坐标转极坐标、向量模长和绝对值计算。

> 注意：两个文件中的顶层模块名都为 `Cordic_Atan2`，不能不加修改地同时编译。24 位与 48 位版本的接口和流水深度也不同，替换时必须重新检查位宽及时序对齐。

### 1.3 `LMS_Transposed` 自适应 FIR 滤波器

文件：`LMS_FIR_Transposed.v`

该模块实现 TAPS 阶 LMS 自适应 FIR：

```text
y(n) = Σ w_k(n) · x(n-k)
e(n) = d(n) - y(n)
w_k(n+1) = w_k(n) + μ · e(n) · x(n-k)
```

默认参数为 32 抽头、14 位 Q1.13 数据、32 位 Q1.29 系数。`i_mu` 不是直接乘法系数，而是参与算术右移的步长指数：数值越大，有效步长越小，通常收敛更慢、稳态误差更小。`i_freeze=1` 时停止更新权值，但仍继续滤波。

当前输出乘加和权值更新包含较长的组合路径，抽头数较多或目标频率较高时可能产生时序压力。上板前应查看综合后的时序报告；需要提高频率时，可把乘加过程改成流水加法树。

### 1.4 `LMS_IIR` 自适应 IIR 系数辨识器

文件：`LMS_IIR.v`

该模块采用方程误差法训练三路前馈系数和两路反馈系数。默认数据格式为 14 位 Q1.13，系数格式为 32 位 Q3.28，并通过 `o_a0`～`o_a2`、`o_b0`～`o_b1` 输出当前系数。

它的反馈训练量来自期望信号 `i_dn`，关系为：

```text
y(n) = Σ a_k · x(n-k) + Σ b_k · d(n-k)
e(n) = d(n) - y(n)
```

因此它更适合做在线参数辨识，而不应把冻结后的 `o_yn` 直接当作标准 IIR 滤波结果。系数收敛后，应把输出系数交给 `IIR_Designer`，由后者使用自身输出反馈完成实际滤波。

虽然抽头数以参数形式声明，当前端口和系数映射固定为 3 个前馈抽头、2 个反馈抽头；修改抽头数时还需同步修改接口与映射代码。

### 1.5 `IIR_Designer` 固定系数 IIR 滤波器

相关文件：

- `IIR_Designer.v`：固定系数直接型 IIR RTL；
- `iir_designer.m`：MATLAB 系数设计、定点量化和频率响应对比脚本。

RTL 实现关系为：

```text
y(n) = a0·x(n) + a1·x(n-1) + a2·x(n-2)
     + b0·y(n-1) + b1·y(n-2)
```

默认数据格式为 14 位 Q1.13，系数格式为 32 位 Q3.28。MATLAB 脚本支持 Butterworth、Chebyshev I/II 和 Elliptic 滤波器，可配置低通、高通、带通或带阻类型，并将 MATLAB 分母系数取反后生成 RTL 所需的反馈系数。

当前源码有两项使用约束：

- 系数端口固定为 3 个前馈和 2 个反馈抽头，调整参数时需要同步扩展端口和映射；
- `IIR_Designer.v` 输出饱和表达式中的 `1'i_b0`、`1'i_b1` 不是合法 Verilog 数字字面量，综合前应改为对应的 `1'b0`、`1'b1`。

### 1.6 `LFSR_Generator` 伪随机序列发生器

文件：`LFSR_Generator.v`

模块使用 32 位 LFSR 和多项式 `x^32 + x^22 + x^2 + x + 1`，复位种子为非零值 `32'hA3C5_1F2E`。每拍更新一次序列，理论周期为 `2^32-1`。

`o_noise_out` 并不是由多个独立随机位组成，而是把 LFSR 的 bit 0 复制到整个 `DOUT_WIDTH` 总线，因此每拍只输出全 0 或全 1。它适合作为一比特伪随机激励、抖动或扩频控制信号；若需要多位幅度白噪声，应重新选择多个 LFSR 位、做符号映射或叠加多个独立序列。

## 第二章：模块组合功能

### 2.1 正交载波与可调波形发生器

```text
频率字/调制字 → 相位累加器 → Cordic → cos、sin
```

相位每拍固定递增时可生成连续正弦、余弦；改变相位步进可实现 FSK 或 FM；直接改变相位可实现 PSK 或 PM；让相位步进线性变化可生成 LFM/Chirp。24 位版本适合接口简单的全精度 Q1.23 数据通路，48 位版本适合需要更细频率分辨率并希望自定义输出位宽的场景。

### 2.2 直角坐标与极坐标互换

```text
相位 θ → Cordic → (cos θ, sin θ)
(x, y) → Cordic_Atan2 → (模长 r, 相位 θ)
```

两个模块共同构成基础硬件数学单元，可完成正弦/余弦、`atan2`、向量模长、绝对值和坐标变换。把 CORDIC 的 `cos/sin` 输出送入同位宽的 `Cordic_Atan2`，并补偿两个模块不同的流水深度，可以检查恢复相位与原始相位是否一致。

24 位与 48 位组合不能只按模块名直接替换：应先统一相位编码、数据位宽和流水有效信号。若两套版本需要共存，必须重命名模块。

### 2.3 IQ 解调与幅相提取

```text
                         ┌→ × cos → LPF → I ─┐
输入已调信号 ────────────┤                   ├→ Cordic_Atan2 → 幅度、相位
相位累加器 → Cordic ─────└→ × sin → LPF → Q ─┘
```

CORDIC 产生本振正交载波，输入信号分别混频并低通后得到 I/Q 基带，`Cordic_Atan2` 再输出瞬时幅度和相位。幅度可用于 AM 包络解调；相位差分并处理 `±π` 回绕后可用于 FM 解调，也可用于 PSK 相位判决。

仓库尚未提供完整的双路混频器、IQ 低通滤波器、相位解包和差分顶层，因此该功能需要用户补充连接逻辑与有效信号流水。

### 2.4 平方律包络检波、功率与 RMS 测量

对实信号平方后低通，可以滤掉载波附近的高频分量并保留随包络变化的平均功率：

```text
x(n) → 平方器 x²(n) → 低通/滑动平均 → p(n)
                                      ├→ p(n)：功率包络
                                      └→ sqrt(p(n))：幅度/RMS 包络
```

若 `x(t)=A(t)cos(ω_ct)` 且 `A(t)` 的变化远慢于载波，则低通后约有 `p(t)=A²(t)/2`；幅度包络可按 `A(t)≈sqrt(2p(t))` 恢复。省略平方根时得到的是功率包络，也常足以完成门限检测、能量统计和 AGC 控制。

实现时应先把输入解释为有符号数，平方结果使用约两倍位宽，低通后再舍入、截位和饱和。当前仓库可用 `IIR_Designer` 实现低通，但平方器、开平方和有效信号对齐逻辑需要另行补充。对于已经得到 I/Q 的信号，直接使用 `Cordic_Atan2` 的模长输出计算 `sqrt(I²+Q²)`，通常比单路平方律检波更稳定，而且不受载波相位影响。

### 2.5 乘法鉴相、同步检波与相关检测

两路同频正弦信号相乘后低通，可提取相位差相关的基带分量：

```text
x₁(t)=A₁cos(ωt+φ₁)
x₂(t)=A₂cos(ωt+φ₂)

LPF{x₁·x₂} = A₁A₂/2 · cos(φ₁-φ₂)
```

因此可以用“乘法器 + `IIR_Designer` 低通”构成乘法鉴相器、同步检波器或相关器。若参考路使用 CORDIC 生成的正交 `cos/sin`，两路乘积低通后就得到 I/Q；再经 `Cordic_Atan2` 可得到带符号的完整相位差。只使用同相乘积时输出是余弦关系，无法区分 `+Δφ` 和 `-Δφ`，且增益随输入幅度变化，不宜把它直接当作全量程线性相位值。

将已知码型、导频或模板信号作为第二路输入，并把低通改为一个符号周期内的累加，也可以实现相关峰检测、前导码检测和简单匹配滤波。积分窗口、门限与清零控制需要额外逻辑。

### 2.6 FM 解调：IQ 鉴相后相位差分

在 `Empty2.42` 工程中，FM 解调链路采用了以下结构：

```text
FM 输入 ─→ 分别乘以本振 cos/sin ─→ 双路 FIR 低通 ─→ I、Q
                                                      │
                                                      ↓
                                             Cordic_Atan2
                                                      │ phase(n)
                                                      ↓
                                      phase(n)-phase(n-1) ─→ FM 基带
```

其中 `IQ_Solve.v` 使用相位累加器和 `Cordic` 产生正交本振，经过两路乘法及 FIR 低通得到 I/Q；`Cordic_Atan2` 提取瞬时相位；顶层 `Empty.v` 保存上一拍相位并计算 `phase_diff`。该工程的示例参数为 20 MHz 处理时钟、2 MHz 载波、50 kHz 最大频偏和 50 kHz 调制频率。

本仓库保留了这条链路所需的 CORDIC 正反变换核心，但没有收录 `IQ_Solve`、乘法器、双路 FIR 和相位差分顶层。重新搭建时需要注意：

- 让本振频率接近 FM 载波中心频率，否则 `phase_diff` 会叠加固定频偏；
- 两路混频和低通必须完全对称，I/Q 增益或群延迟不一致会产生解调失真；
- 圆周相位使用固定位宽补码，相邻相位直接做同位宽减法即可按模 `2π` 回绕，但必须避免相邻采样的真实相位增量达到或超过 `π`；
- 对 48 位圆周相位，瞬时频率关系为 `f_inst = phase_diff · f_clk / 2^48`，再减去残余中心频偏并按目标量程缩放即可得到 FM 基带；
- 差分会放大高频噪声，实际输出通常还需要一级低通、抽取或去直流。

另一种硬件友好的做法是先计算相邻 IQ 向量的共轭乘积：

```text
re = I(n)·I(n-1) + Q(n)·Q(n-1)
im = Q(n)·I(n-1) - I(n)·Q(n-1)
Δφ = atan2(im, re)
```

该结构直接得到相邻相位差，不需要保存并解包整段绝对相位，在长时间连续 FM 解调中更稳健，代价是增加四个乘法器和两个加减法器。

### 2.7 AM、ASK、FSK 与 PSK 解调

这些基础单元还能构成常见数字/模拟解调器：

| 信号类型 | 推荐组合 | 判决量 |
|---|---|---|
| AM/ASK | 平方律低通，或 IQ 混频后取 `Cordic_Atan2` 模长 | 幅度或功率包络 |
| 相干 AM | 输入乘同步载波，再低通 | 带符号基带幅度 |
| FSK | IQ 鉴相后相位差分，或对多个候选频率分别相关 | 瞬时频率或最大相关支路 |
| BPSK/QPSK | IQ 下变频后用 `atan2(Q,I)`，或直接比较 I/Q 符号 | 星座相位区域 |

实际接收机还需要载波同步、符号定时、AGC 和判决门限。README 中的组合说明表示这些模块可以作为运算核心，并不代表当前目录已提供完整协议接收机。

### 2.8 幅度监测与自动增益控制

平方低通得到的功率包络，或 `Cordic_Atan2` 输出的 IQ 模长，都可以作为 AGC 的幅度观测值：

```text
输入 → 幅度/功率检测 → 目标值比较 → 环路滤波 → 可变增益控制
```

这种组合也可用于过载检测、静噪、突发信号检测和接收信号强度指示。为防止增益在噪声附近抖动，工程中通常加入上下门限、迟滞、攻击/释放时间常数以及增益限幅；可变增益乘法器和控制状态机需要另外实现。

### 2.9 自适应噪声抵消与系统辨识

`LMS_Transposed` 可以用于自适应噪声抵消、回声抵消和未知 FIR 通道辨识：

```text
相关噪声/测试输入 x(n) → LMS_Transposed → y(n)
目标或观测信号 d(n) ───────────────────→ e(n)=d(n)-y(n)
```

若 `d(n)` 中包含由 `x(n)` 经未知通道形成的干扰，LMS 会学习该通道，误差 `e(n)` 可作为抵消后的输出。做系统辨识时，则把收敛权值视作未知 FIR 通道的估计。

`LFSR_Generator` 可提供一比特伪随机测试激励，但其当前多位输出只有两种码值。用于精确幅频辨识前，应确认激励幅度映射、带宽、模拟链路延迟和输入/期望信号对齐满足要求。

### 2.10 IIR 参数辨识与固定滤波

```text
训练输入 x(n) ──→ LMS_IIR ──→ 收敛后的 a/b 系数 ──→ IIR_Designer
期望输出 d(n) ────↑                                  │
实际输入 ─────────────────────────────────────────────→ 固定 IIR 输出
```

`LMS_IIR` 用方程误差结构估计未知系统系数，`IIR_Designer` 再使用这些系数构成真正的输出反馈 IIR。这种分工把“训练/辨识”和“实际滤波”分开，可用于在线或离线估计低阶 IIR 模型。

也可以跳过自适应训练，直接用 `iir_designer.m` 设计并量化系数，再送给 `IIR_Designer.v`。无论系数来自 MATLAB 还是 LMS，使用前都应检查极点稳定性、量化误差、符号约定和输入输出增益。

## 第三章：总结

这些模块单独看都不复杂，但组合起来能做的事情很多：CORDIC 可以包办正弦、余弦、模长和相位，乘法器配低通可以做包络检波、鉴相和同步解调，LMS 可以做自适应滤波和系统辨识。FPGA 的好处就是并行，需要多处理一路信号时，资源够就直接多例化一路，各条通路同时跑，不用像软件那样排队等中断。

写这类 DSP 代码，真正容易出问题的往往不是公式，而是有符号数、位宽、截位、饱和、移位方向和流水延迟。代码能综合不代表数值一定正确，单个模块仿真正确也不代表连起来以后时序就天然对齐。所以还是建议先在 MATLAB 里把算法和定点量化算明白，再用 RTL testbench 把零值、满量程、象限边界、相位回绕和溢出这些情况都跑一遍，确认以后再上板。

如果仿真是对的，上板却不对，通常不是“仿真没用”，而是仿真里还缺了真实硬件中的某些东西，比如 ADC/DAC 延迟、滤波器群延迟、接口握手、跨时钟域、模拟通路增益或者噪声。找到板上和仿真的差别以后，就把这些因素继续补进模型里。调试的过程说到底就是让**仿真越仿越真**，而不是仿一次通过就把 testbench 丢到一边。
