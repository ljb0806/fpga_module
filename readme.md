# FPGA 模块使用注意事项

## 1. Cordic — 正弦/余弦计算器

### 功能概述

基于 CORDIC 旋转模式的正弦/余弦计算器，输入相位角（Q23 定点），输出对应的 cos 和 sin。

### 典型用途

- **正弦波生成**：输入一个线性递增的相位（相位累加器），即可产生标准正弦/余弦波形。相比传统查表法（LUT），CORDIC 精度更高且不消耗 ROM 资源。
- **LFM 线性调频波**：将相位改为二次方变化（相位累加器的增量本身也在线性变化），即可产生 chirp 信号，用于雷达脉冲压缩等场景。
- **任意调频/调相**：只需控制 phase_in 的变化规律，即可灵活生成各种调制波形（FSK、PSK 等）。

### 注意事项

- **流水线延迟**：24 级流水线 + 1 级象限预处理，总共 **25 个 clk** 的固定延迟，使用时需注意相位输入与波形输出之间的时序对齐。
- **Q23 定点格式**：π 对应 `0x800000`，相位累加时需注意模 2π 的溢出回绕（利用有符号数自然溢出即可）。
- **幅度**：输出 cos/sin 范围为 ±(2^23 - 1)，对应浮点 [-1, 1)。

## 2. Cordic_Atan2 — 反正切/模长计算器

### 功能概述

基于 CORDIC **向量模式（Vectoring Mode）** 的反正切计算器，输入向量坐标 (x, y)，输出 atan2(y, x) 和模长。与 Cordic 互为镜像——一个角度转坐标，一个坐标转角度。

### 与 Cordic 的关系

| | Cordic（旋转模式） | Cordic_Atan2（向量模式） |
|---|---|---|
| 方向判决 | z_reg < 0 | y_reg >= 0 |
| 驱动目标 | z → 0 | y → 0 |
| 输入 | 角度（Q23） | 向量 (x, y)（Q23） |
| 输出 | cos, sin | atan2, 模长 |
| 延迟 | 25 clk | 25 clk |

### 增益预补偿

向量模式迭代会放大模长 ×1.647，本模块在输入级乘以 CORDIC_GAIN 预补偿，确保输出模长为 unity gain，且不会溢出。预补偿不改变 atan2 结果（等比例缩放对角度无影响）。

### 数学运算能力

Cordic_Atan2 本质是一个硬件数学运算单元，输入 (x, y) 同时输出 atan2 和模长，可覆盖多种初等函数：

| 数学运算 | 输入配置 | 输出 | 公式 |
|----------|----------|------|------|
| **atan2(y, x)** | x_in=x, y_in=y | phase_out | θ = atan2(y, x) |
| **sqrt(x² + y²)** | x_in=x, y_in=y | phase_out_mag | r = √(x² + y²) |
| **求绝对值** | x_in=a, y_in=0 | phase_out_mag | r = \|a\| |
| **求相位角** | x_in=a, y_in=b | phase_out | θ = atan2(b, a) |

输入任意直角坐标 (x, y)，一步同时得到极坐标 (r, θ)，不需要另开 sqrt 或除法运算。

### Cordic + Cordic_Atan2：硬件数学协处理器

两个模块加在一起，覆盖了 DSP 最常用的初等函数，全硬件实现，不吃 RAM，只用加法器和移位器：

| 函数 | 使用模块 | 说明 |
|------|----------|------|
| sin θ, cos θ | Cordic | 旋转模式，输入角度 |
| sin θ, cos θ 同时 | Cordic | 双路输出，正交载波 |
| atan2(y, x) | Cordic_Atan2 | 向量模式，输入坐标 |
| √(x² + y²) | Cordic_Atan2 | 欧几里得范数 |
| 直角 → 极坐标 | Cordic_Atan2 | (x,y) → (r, θ)，一步 |
| 极坐标 → 直角 | Cordic | (r, θ) → (x,y)，r 乘入初始 x₀ |
| arcsin / arccos | Cordic_Atan2 | arcsin(a) = atan2(a, √(1-a²))，需配套计算 |

均为 25 clk 固定延迟，相比 Vivado CORDIC IP 核更灵活可定制。

### 与 Cordic 闭环验证

Cordic 发 cos/sin → 经过信号链路 → Cordic_Atan2 鉴相，输出相位应等于原始输入相位。该闭环链路已仿真验证通过。

## 3. LMS_FIR_Transposed — LMS 自适应 FIR 滤波器

### 功能概述

TAPS 阶 LMS 自适应 FIR 滤波器，通过在线调整权值使输出逼近期望信号。

### 时序问题

- 当前采用转置结构，权值更新与滤波输出均通过组合逻辑在大规模乘加树中完成，**组合逻辑级数较高**。
- **上板前请注意**：如果工作频率较高（如 >100 MHz），该模块可能出现**时序违例**（setup time 不满足）。
- **优化建议**：可将输出计算 `y_acc = Σ w_k * x(n-k)` 改为流水线加法树（多级寄存器打拍），以时序换频率，使模块适应高频工作环境。

### 其他

- `mu` 为步长指数，通过算术右移量控制收敛速度与稳态误差的权衡。mu 越大步长越小、收敛越慢但稳态误差越小。
- `freeze` 可冻结权值更新，将滤波器退化为固定系数 FIR。

## 4. LMS_IIR — LMS 自适应 IIR 滤波器

### 功能概述

采用**方程误差法（Equation-Error）** 的 LMS 自适应 IIR 滤波器。反馈回路的参考信号为期望信号 `dn`（而非自身输出 `yn`），保证了误差曲面为二次型，LMS 可收敛到全局最优。

### 关键注意事项

- **不要直接使用冻结后的 yn 作为滤波输出**：由于本模块的反馈取自 `dn` 而非 `yn`，即使冻结系数，其输出特性与实际 IIR 滤波器（反馈取自自身输出）并不等价。
- **正确用法**：将 LMS_IIR 训练收敛后的系数（a0/a1/a2, b0/b1）取出，**重新例化一个 IIR_Designer 模块**，用该系数做真正的 IIR 滤波。即：

```
LMS_IIR（训练系数）→ 提取收敛后的 a/b → IIR_Designer（实际滤波）
```

---

## 5. IIR_Designer — 固定系数 IIR 滤波器

### 功能概述

固定系数直接型 IIR 滤波器，反馈取自自身输出 `yn`，是标准的 IIR 实现。

### 配合使用

- **与 `iir_designer.m` 配合**：在 MATLAB 中运行 `iir_designer.m`，设定滤波器类型、截止频率等参数，生成 Q28 定点系数，填入本模块。
- **与 `LMS_IIR` 配合**：LMS_IIR 在线训练得到系数后，将系数接入本模块做实际滤波输出。

### 定点格式

- 数据 Q1.13（DWIDTH=14），系数 Q3.28（CWIDTH=32, FRACBITS=28），与 LMS_IIR 保持一致，系数可直接复用。

## 6. NCO — 数控振荡器（DPLL 振荡器）

### 功能概述

数字锁相环（DPLL）的数控振荡器：根据中心频率控制字与环路滤波器修正量累加相位，查正弦 ROM 表产生正弦波输出。

### 工作原理

- **相位累加**：每个时钟周期 `phase_acc` 累加 `step = i_FREQ_INIT + 符号扩展(i_FREQ_CTRL)`，即中心频率 + 环路滤波器修正量
- **查表输出**：取相位累加器高 12 位作为地址查 `SINROM_4096_16` 正弦 ROM
- **有符号输出**：`o_nco_out_signed` 通过翻转 MSB，将无符号 ROM 输出转为二进制补码有符号数

### 参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| DWIDTH | 16 | 输出数据位宽 |
| PWIDTH | 48 | 相位累加器位宽 |
| AWIDTH | 12 | ROM 地址位宽（查表深度 4096） |
| CWIDTH | 40 | 环路滤波器控制字位宽（有符号，≤ PWIDTH） |

### 端口说明

- `i_FREQ_INIT`：初始/中心振荡频率控制字（无符号）
- `i_FREQ_CTRL`：环路滤波器输出的频率修正控制字（有符号补码）
- `o_nco_out` / `o_nco_out_signed`：正弦波输出（无符号 / 有符号）

### 注意事项

- **依赖 IP**：需要 `SINROM_4096_16` 正弦 ROM IP（Vivado Block Memory Generator），使用前先生成该 IP
- 频率分辨率：48 位累加器，频率控制字与时钟频率关系为 `f_out = f_clk × step / 2^PWIDTH`
- 与 Cordic 的关系：Cordic 也可以生成正弦波（无 ROM），NCO 用查表法资源更省，两者可按需替换

## 7. PD — 鉴相器（乘法鉴相 + FIR 低通）

### 功能概述

数字锁相环（DPLL）的鉴相器：对两路输入信号做**乘法鉴相**，并经低通 FIR 滤波提取相位误差 `o_phase`，供后续环路滤波器（PI_Filter）使用。这正是前文"高频信号：乘法鉴相 + 低通滤波"方案的工程实现。

### 工作原理

- **乘法鉴相**：两路同频信号相乘 `mul_res = i_data_A × i_data_B`，产生和频与差频（含直流/相位差）分量
- **截位**：取乘法结果高位 `mul_res[31:16]` 送入 FIR 低通滤波器
- **低通滤波**：`fir_compiler_0` 滤除和频分量，保留反映相位差的低频分量，输出 `o_phase`

### 参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| DIN_WIDTH | 16 | 输入数据位宽 |
| DOUT_WIDTH | 40 | 相位误差输出位宽（需与 FIR 配置一致） |

### 注意事项

- **依赖 IP**：需要 `fir_compiler_0` FIR 低通滤波器 IP（Vivado FIR Compiler），且其输出位宽须与 `DOUT_WIDTH` 一致
- **输入要求**：两路输入为有符号数，通常一路为参考信号、一路为 NCO 反馈信号

---

## 8. PI_Filter — 环路滤波器（PI 结构）

### 功能概述

数字锁相环（DPLL）的环路滤波器，采用**比例-积分（PI）结构**：将鉴相器输出的相位误差 `i_err` 转换为频率控制字 `o_ctrl`，驱动 NCO 完成闭环锁定。

### 工作原理

- **比例支路**：`P = err_ext <<< KP`（左移 3 位 = ×8），当前误差立即反映到输出
- **积分支路**：`I = err_ext >>> KI`（右移 9 位 = ÷512），误差逐步累积消除稳态误差
- **积分饱和**：积分累加结果限幅在 `[-LIMIT, +LIMIT]`，防止积分器溢出或缠绕
- **输出**：`o_ctrl = P + integ`，比例支路取当前误差，积分支路取上一周期累积值

### 参数说明

| 参数 | 默认值 | 含义 |
|------|--------|------|
| EWIDTH | 40 | 误差输入位宽 |
| UWIDTH | 40 | 控制字输出位宽（内部运算位宽） |
| KP | 3 | 比例增益：左移 3 位 = ×8 |
| KI | 9 | 积分增益：右移 9 位 = ÷512 |
| LIMIT | 40'h40_0000_0000 | 积分饱和上限（有符号 = 2^38） |

### 注意事项

- **位宽扩展**：40 位误差符号扩展至 40 位运算位宽，避免运算溢出
- **环路带宽**：KP 决定环路响应速度，KI 决定稳态精度；KP 过大会振荡，KI 过大会降低环路稳定性，需根据环路特性仿真调参

---

## DPLL 闭环：PD → PI_Filter → NCO

三个模块串联构成完整的数字锁相环：

```
参考信号 ──→ PD（乘法鉴相 + FIR 低通）──→ PI_Filter（环路滤波）──→ NCO（振荡器）
                 ↑                                                        │
                 └──────────────── 反馈回路 (o_nco_out_signed) ←──────────┘
```

- **PD** 提取参考信号与 NCO 输出之间的相位误差
- **PI_Filter** 将相位误差转换为频率修正控制字（P 快调 + I 细调）
- **NCO** 在中心频率基础上叠加修正量，输出逐渐锁相的正弦波
- 闭环锁定后，NCO 输出频率/相位与参考信号对齐，`i_FREQ_CTRL` 趋于稳定值

该闭环可配合前文"鉴相器"章节的三种鉴相方案互相替换验证：乘法 + LPF（本 PD）、XOR + 占空比（资源最省）、Cordic_Atan2（高精度带符号）。

# 用 FPGA 实现一些软件算法的思路

FPGA 的并行硬件特性使其在实时信号处理中具有天然优势，许多软件算法可以通过简单的硬件结构直接实现，无需 CPU/DSP 的逐指令执行。

## 鉴相器（Phase Detector）

鉴相器用于提取两个同频信号之间的相位差，在锁相环、雷达测距、通信解调等场景中广泛应用。FPGA 上可根据信号频率选择不同实现方式：

### 高频信号：乘法鉴相 + 低通滤波

将两路信号相乘后做低通滤波，提取直流分量即为相位差信息：

```
s1(t) = A1 * sin(ωt + φ1)
s2(t) = A2 * sin(ωt + φ2)

s1 * s2 = (A1*A2)/2 * [cos(φ1-φ2) - cos(2ωt + φ1+φ2)]
                ↑ 直流分量 (正比于相位差)     ↑ 二倍频分量 (被 LPF 滤除)
```

FPGA 实现：乘法器（DSP slice）+ IIR/FIR 低通滤波器，乘法后的高频分量由 LPF 滤除，输出即为 `cos(Δφ)`。

### 低频信号：异或门鉴相 + 占空比测量

当信号频率较低时，可以简化设计：

1. 取两路信号的**符号位**（最高位，0/1 即正/负）
2. 两符号位做**异或（XOR）**运算
3. 异或输出为高电平时表示两信号极性相反，低电平时极性相同
4. 测量异或输出的**占空比**（高电平占比），即可换算相位差

```
相位差 = 占空比 × 180°（异或输出为 1 的占比）
```

例如占空比为 25%（0.25），则相位差 = 0.25 × 180° = 45°。

FPGA 实现：符号位提取（直接连线）→ XOR 门 → 计数器测量高电平周期数 / 总周期数 → 相位差值。此方案几乎不消耗 DSP 和 RAM 资源，仅需逻辑门和少量寄存器，非常适合资源受限的低频场景。

### 通用方法：Cordic_Atan2 鉴相

当两路信号已经是正交的 IQ 形式（例如经过 IQ 解调后的基带信号），可以直接用 Cordic_Atan2 提取相位：

```
I(t) = A * cos(φ)
Q(t) = A * sin(φ)
              ↓
        Cordic_Atan2
              ↓
    phase_out = φ (Q23 定点)
```

与其他两种方法相比：

| | 乘法 + LPF | XOR + 占空比 | Cordic_Atan2 |
|---|---|---|---|
| 精度 | cos(Δφ)，小角度时灵敏度低 | 受谐波和噪声影响大 | 直接输出 φ，全量程一致 |
| 相位符号 | 无法区分 ±φ（cos 是偶函数） | 无法区分 ±φ | 区分 ±φ（atan2 带符号） |
| 资源 | 1 DSP + 滤波器 | 极少 | 约 24×3 寄存器 + 加法器 |
| 延迟 | 滤波器相关 | 约 1 个信号周期 | 固定 25 clk |
| 适用前提 | 同频正弦信号 | 同频方波/正弦 | 需先有 IQ 基带信号 |

**结论**：乘法 + LPF 适合快速粗略鉴相，XOR 适合资源极受限的低频场景，Cordic_Atan2 适合已有 IQ 基带、要求高精度且能区分正负相位的场景。三者可以组合使用——例如 IQ 解调 + Cordic_Atan2 鉴相，就是完整的数字鉴相器方案。

## IQ 解调（AM / FM 解调）

IQ 解调是数字接收机的核心架构，利用正交的 I、Q 两路载波将已调信号下变频到基带，再从 I/Q 分量中提取幅度和相位信息，实现各种调制信号的解调。

### 基本原理

```
已调信号 s(t) = A(t) * cos(ωc*t + φ(t))   ← AM: A(t) 承载信息, FM: φ(t) 承载信息

I 路: s(t) * cos(ωc*t) ──LPF──→ I = A(t)/2 * cos(φ(t))
Q 路: s(t) * sin(ωc*t) ──LPF──→ Q = A(t)/2 * sin(φ(t))

瞬时幅度: A(t) = 2 * sqrt(I^2 + Q^2)     → AM 解调输出
瞬时相位: φ(t) = atan2(Q, I)              → FM 解调输出 (对 φ 求导得频率)
```

### FPGA 实现流程

```
                        ┌─→ 乘法器 ─→ LPF ─→ I ─┐
Cordic ─→ cos/sin ─┤                          ├─→ sqrt(I²+Q²) ──→ AM 输出
(正交载波)           └─→ 乘法器 ─→ LPF ─→ Q ─┘   or atan2(Q,I) ─→ FM 输出
        ↑
   phase_acc (相位累加器, 调谐到载波频率)
```

1. **正交载波生成**：使用 Cordic 模块 + 相位累加器产生 cos(ωc*t) 和 sin(ωc*t) 两路正交载波
2. **混频**：已调信号分别与 I/Q 两路载波相乘（两个乘法器）
3. **低通滤波**：滤除 2ωc 高频分量，得到基带 I/Q 信号
4. **解调输出**：
   - **AM 解调**：`sqrt(I² + Q²)` 提取瞬时幅度。若已做载波同步，可直接取 I 路
   - **FM 解调**：`atan2(Q, I)` 提取瞬时相位，再对相位求差分得到瞬时频率。也可再用一个 Cordic 来做 atan2

### 与 Cordic 的关系

本仓库的 Cordic 和 Cordic_Atan2 两个模块正好覆盖 IQ 解调的两端：

| 模块 | 模式 | 用途 |
|------|------|------|
| **Cordic** | 旋转模式 | 生成正交载波 cos/sin |
| **Cordic_Atan2** | 向量模式 | 基带鉴相 atan2(Q, I)，用于 FM 解调 |

两个模块可以直接串联验证：Cordic 发 cos/sin → 经过处理链路 → Cordic_Atan2 鉴相，输出相位应等于原始输入。已验证通过。

# 方案分享：2025 年 G 题 — 模拟滤波器数字孪生

题目要求对一个物理模拟滤波器建立数字孪生模型，即用一个数字滤波器去复现它的幅频/相频响应。自适应 IIR 在这道题上有天然优势——模拟滤波器本质就是 IIR 结构（有极点），用 IIR 去拟合比 FIR 更对路。

## 整体思路

```
LFSR_Generator ──→ DAC ──→ [模拟滤波器] ──→ ADC ──→ dn ─┐
     │                                                    │
     └────── 延时补偿 ──→ xn ─────────────→ LMS_IIR ──────┘
                                                    │
                                              收敛后的 a/b
                                                    │
                                                    ↓
                                            IIR_Designer
                                          (数字孪生滤波器)
```

1. **LFSR_Generator** 产生白噪声 —— 白噪声在频带上是平坦的，用它扫频等效于同时测所有频率点的响应
2. 白噪声经 DAC 输出，**送入待测模拟滤波器**，再经 ADC 采回，得到的就是被滤波器"染色"后的信号——其频谱即为滤波器响应
3. 采回信号作为 **LMS_IIR 的期望信号 dn**，原始白噪声序列作为 **输入 xn**，LMS 在线学习
4. 收敛后的系数交给 **IIR_Designer**，得到的数字滤波器就具备了待测模拟滤波器的响应——数字孪生完成

## 已验证及注意事项

该方案笔者已上板验证可行。实际调试中需注意两点：

- **延时补偿**：DAC→模拟滤波器→ADC 这一圈有硬件延迟，xn 需要做相应的延迟对齐，否则 LMS 几乎无法收敛
- **增益校准**：整个通路的增益不一定是 1（DAC 量程、滤波器插损、ADC 量程都会引入增益因子），最后需要对整个系统做一次增益校准，让数字孪生滤波器的响应和物理滤波器的响应在幅度上完全对齐

这个方案巧在用了 LFSR 产生白噪声作为激励，不需要扫频、不需要 chirp、不需要离线 FFT，一个模块发噪声、一个模块学，全程硬件在线跑，非常省事。

# 总结

用 Verilog 负责 DSP，硬件通路一旦跑通就是很稳定的，不像软件那样担心中断延迟和 CPU 负载。Modelsim 和 matlab 里仿真什么样，上板基本就什么样，调试也容易。

实际项目中，建议 PL 端包揽所有 DSP 部分——乘法器、滤波器、Cordic、调制解调等，PS 端只干串行控制、参数控制、配寄存器、状态机这些它擅长的活。两边各干各的，互不拖累。

另外，FPGA 的并行特性在信号题中优势很明显。比如需要同时处理多路信号、同频显示输入和滤波后波形、或者实时比对频谱——这些用单片机要分时复用，每加一路就多一份中断开销，而 FPGA 直接多例化一路模块，资源换并行，各跑各的谁也不等谁。

## FPGA 开发建议

新手写 Verilog 最容易栽在几个地方：有符号数和无符号数混用、位宽没对齐、截位、溢出、移位方向搞反以及运算符的运算顺序等。这些问题在代码里不报错，上板现象五花八门，很难直接定位到代码行。

所以建议**先把仿真跑通再上板**。MATLAB 做算法级验证，Modelsim 做 RTL 级验证——仿真过了，上板基本就过了。靠 SignalTap 抓信号来调试效率很低，一是能抓的信号量有限，二是每次改抓取点都要重新综合，来回折腾时间成本很高。

如果仿真过了上板没过，那说明仿真里漏掉了某些实际因素（比如硬件时延、接口时序、跨时钟域等）。这时候再上板抓波形，对照仿真找差异——仿真为什么是对的？板上为什么不一样？然后把漏掉的因素补进仿真，让仿真越来越逼近真实硬件。**仿真要越仿越真**，而不是仿一次就丢。
